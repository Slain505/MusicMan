# Music GO

Гуляешь по городу, ловишь дропы на карте, собираешь музыку.

```
core/    чистый Dart: генерация точек, RNG, валидатор поимки (общий для клиента и сервера)
server/  Dart (shelf): проверка поимок, коллекции, прокси к Deezer / Odesli, раздача веб-сборки
app/     Flutter-клиент (web / Android / iOS)
```

## Запуск на localhost

Flutter установлен в `%USERPROFILE%\flutter`. Если `flutter` не находится, добавь `%USERPROFILE%\flutter\bin` в PATH.

```powershell
cd app;    flutter pub get; flutter build web
cd ..\server; dart pub get; dart run bin/server.dart      # http://localhost:8080
```

Флаги сервера:
- `--dev`: отключает анти-чит по скорости, телепорт в симуляторе будет проходить;
- `--port 8080`, `--data data/players.json`.

Переменная окружения `ODESLI_API_KEY`: с ключом приходят прямые ссылки на трек в Spotify, Apple Music и YouTube. Без ключа это ссылки на поиск.

Для горячей перезагрузки UI запусти сервер как выше и дополнительно:
```powershell
cd app; flutter run -d chrome --dart-define=API_BASE=http://localhost:8080
```

## Управление в симуляторе
- клик по карте: идти туда (8 м/с);
- WASD / стрелки: шаг 15 м;
- долгий клик: телепорт. Сервер отклонит следующую поимку как подмену GPS (если не запущен с `--dev`);
- клик по дропу в радиусе 40 м: поймать.

## Как устроено
- **Точки не хранятся.** Мир делится на ячейки ~200 м. Из `(seed мира, ячейка, временное окно)` детерминированно получаются точки: плотность задаёт шум, в каждом «районе» ~2 км свой жанр. Обновление ячеек разнесено по времени. Клиент и сервер считают одно и то же. Тест `core/test` сверяет эталонный отпечаток на VM и в Chrome (`dart test -p chrome`).
- **Сервер — источник истины:** проверяет, что точка существует, что игрок рядом, не пойман ли дроп уже и не телепортировался ли игрок.
- **Музыка:** трек берётся из чарта Deezer по жанру (без ключа). 30-секундное превью запрашивается свежим при открытии карточки (ссылки Deezer подписаны и протухают).
- **Батарея:** без поллинга. Точки пересчитываются только после 60 м пути или при истечении ближайшего дропа (один таймер). GPS с `distanceFilter: 5`, фоновой геолокации нет.


## Перед релизом
- тайлы: публичные тайлы OSM только для разработки, нужен MapTiler / Stadia / свой сервер;
- хранилище: JSON-файл → Postgres (Supabase) + нормальная авторизация;
- анти-чит: Play Integrity / App Attest;
- права на музыку: превью Deezer подходят для прототипа, для коммерческого запуска нужно проверить их условия.
